# strayCatCafe

포켓몬처럼 길에서 **길고양이·강아지를 만나 친해져서 데려오고**, 그 아이들로 **고양이 카페를 운영**하는 픽셀 타이쿤입니다. 동네를 돌아다니며 덤불 뒤에 숨은 아이에게 살금살금 다가가 간식을 건네고, 마음을 연 아이를 카페로 데려오면 손님이 찾아와 돈을 냅니다. 그림·효과음·배경 음악을 전부 코드로 만들어서 아트·사운드 에셋이 없습니다. Unity 6, C#.

## 요구 사항

- **Unity 6000.0.84f1** (Unity 6 LTS) — [Unity Hub](https://unity.com/download)로 설치
- Git

## 시작하기

1. 저장소를 클론하고 Unity Hub에서 **Add** → 폴더를 선택해 엽니다.
2. 메뉴 **Tools > Project > Play StrayCatCafe** 를 누르면 `Assets/Scenes/StrayCatCafe.unity` 를 열고 바로 실행됩니다.

## 조작

- 방향키 / WASD = 이동
- Shift = 살금살금 (길에 있는 아이의 경계심이 오르지 않습니다)
- Space = 아이에게 간식 주기 · 간식 가게 열기 · 밥그릇 채우기 · 운영 메뉴 열기 · 아이 쓰다듬기
- Q / 1~4 = 건넬 간식 고르기 (동네에서)
- Tab = 도감
- 메뉴 안: ↑↓ 고르기, Space 구입, Esc 닫기
- M = 배경 음악 켜고 끄기
- 하루 정산 화면: Space = 다음 날, Backspace = 새 게임

## 규칙

- **영업**: 09:00~21:00 (실제 약 150초). 끝나면 손님이 돌아가고 정산 화면이 뜹니다. 진행은 자동 저장됩니다.
- **길에서 만나기**: 덤불·나무 근처 풀밭에 아이들이 숨어 있습니다. 가까이서 빨리 움직이면 **경계심**이 올라 도망가고, Shift 로 천천히 다가가면 내려갑니다. 간식을 주면 **친밀도**가 오르고, 다 차면 주인을 따라옵니다. 카페 문으로 들어가면 식구가 됩니다.
- **간식**: 멸치 · 참치캔 · 츄르 · 육포. 고양이와 강아지가 좋아하는 정도가 다르고, 품종마다 **좋아하는 간식**(친밀도 1.8배)이 있습니다. 동네 간식 가게에서 삽니다.
- **품종**: 고양이 19종(치즈냥·턱시도·고등어·삼색이·흰둥이·까망이·러시안블루·샴·코리안숏헤어·페르시안·먼치킨·스코티시폴드·메인쿤·벵갈·랙돌·브리티시숏헤어·스핑크스·노르웨이숲·아비시니안), 강아지 8종(시바견·웰시코기·말티즈·푸들·닥스훈트·진돗개·골든리트리버·달마시안). 장모종(페르시안·메인쿤·랙돌·노르웨이숲)은 털이 더 풍성하게 그려집니다. 도감은 16종씩 ←→ 로 넘깁니다. 흔함·가끔·희귀 세 등급이 있고 날이 갈수록 희귀한 아이가 조금 더 자주 나옵니다. 성격(소심·호기심·장난꾸러기·느긋함)에 따라 처음 경계심과 도망칠 확률이 다릅니다.
- **카페**: 손님은 입장료 3,000원을 내고, 좋아하는 종류(고양이파·강아지파·둘 다)의 아이가 기분 좋게 있으면 한 마리마다 팁 500원을 더 냅니다. 아이들의 **매력** 합계가 높을수록 손님이 자주 옵니다. 아이가 한 마리도 없으면 손님은 둘러보고 그냥 나갑니다.
- **돌보기**: 아이들은 시간이 지나면 배가 고파지고, 굶으면 기분이 나빠져 매력이 떨어집니다. 사료를 사서 밥그릇을 채워 두면 알아서 먹습니다. 쓰다듬어 주거나 손님이 쓰다듬으면 기분이 좋아집니다.
- **업그레이드** (카운터 옆 운영 메뉴): 귀여운 간판(손님 빈도), 푹신한 방석(기분 상한선), 큰 캣타워(매력), 가게 확장(수용 마리수 6 → 10).

## 테스트

Unity **Window > General > Test Runner** 의 EditMode 탭에서 실행합니다. 배치도 연결성, 도감·간식 카탈로그, 친해지기 로직, 경제·저장을 검사합니다. 편집기를 닫은 상태라면 터미널에서도 돌릴 수 있습니다.

```bash
/Applications/Unity/Hub/Editor/6000.0.84f1/Unity.app/Contents/MacOS/Unity -batchmode -projectPath . -runTests -testPlatform EditMode -testResults Logs/results.xml -logFile Logs/test.log
```

## 구조

- `Species.cs` · `Encounter.cs` — 도감·간식 카탈로그와 친해지기 로직 (순수 C#)
- `CafeMap.cs` · `TownMap.cs` · `TileGrid.cs` — 문자 배치도와 길찾기
- `CafeEconomy.cs` · `Animal.cs` — 돈·재고·업그레이드·식구 상태와 저장
- `CafeArt.cs` · `PixelCanvas.cs` · `CafeAudio.cs` — 코드로 만드는 그림과 소리
- `AnimalView.cs` · `StrayView.cs` · `Customer.cs` · `CharacterView.cs` — 카페 식구, 길 위의 아이, 손님 행동
- `Assets/Tests/EditMode/` — EditMode 테스트
