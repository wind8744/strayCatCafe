# strayCatCafe

포켓몬처럼 길에서 **길고양이·강아지를 만나 친해져서 데려오고**, 그 아이들로 **고양이 카페를 운영**하는 픽셀 타이쿤입니다.

이야기는 주인공의 **집**에서 시작합니다. 첫 산책을 나가면 웬 고양이가 졸졸 따라오고, 집으로 데려가면 얼떨결에 같이 살게 됩니다. 그 뒤로 동네의 **풀숲·나무·물가**를 돌아다니며 숨어 있는 아이에게 살금살금 다가가 간식을 건네고, 마음을 연 아이를 집으로 데려옵니다. 집은 3마리까지만 돌볼 수 있는데, 3마리가 모이면 동네 한가운데 **빈 가게를 빌려 고양이 카페를 열고** 손님을 받기 시작합니다. 그림·효과음·배경 음악을 전부 코드로 만들어서 아트·사운드 에셋이 없습니다. Unity 6, C#.

## 요구 사항

- **Unity 6000.0.84f1** (Unity 6 LTS) — [Unity Hub](https://unity.com/download)로 설치
- Git

## 시작하기

1. 저장소를 클론하고 Unity Hub에서 **Add** → 폴더를 선택해 엽니다.
2. 메뉴 **Tools > Project > Play StrayCatCafe** 를 누르면 `Assets/Scenes/StrayCatCafe.unity` 를 열고 바로 실행됩니다.

## 조작

- 방향키 / WASD = 이동
- Shift = 살금살금 (길에 있는 아이의 경계심이 오르지 않습니다)
- Space = 아이에게 간식 주기 · 다친 아이 치료 · 간식 가게 열기 · 밥그릇 채우기 · 카운터에서 주문 만들기 · 아이 쓰다듬기 · 빈 가게 앞에서 카페 열기
- O = 카운터 옆에서 운영 메뉴 (업그레이드·알바 고용)
- Q / 1~4 = 건넬 간식 고르기 (동네에서)
- Tab = 수집북 (스타듀밸리식 그림 격자, 방향키로 골라 상세 보기)
- 메뉴 안: ↑↓ 고르기, Space 구입, Esc 닫기
- M = 배경 음악 켜고 끄기
- 하루 정산 화면: Space = 다음 날, Backspace = 새 게임

## 진행

1. **집** — 아래 문으로 나가 산책합니다.
2. **첫 고양이** — 길에서 코리안숏헤어가 따라옵니다. 집(왼쪽 위 집 문)으로 돌아가면 식구가 됩니다.
3. **모으기** — 풀숲·물가에서 아이들을 찾아 간식으로 친해집니다. 집은 3마리까지.
4. **카페 개업** — 3마리가 모이면 빈 가게(동네 가운데 분홍 지붕) 문 앞에서 Space로 카페를 엽니다. 아이들이 카페로 옮겨 가고 손님이 오기 시작합니다. 이후엔 카페 수용 인원 6마리(확장 시 10마리)까지 데려올 수 있습니다.
5. **장사와 알바** — 손님은 카운터 앞 줄에 서서 커피·간식을 주문합니다. 카운터 옆에서 Space를 누르면 주문을 만들어 값을 받습니다. 운영 메뉴(카운터 옆 O)에서 **바리스타 알바**를 고용하면 주인이 밖에 나가 있는 동안에도 주문을 처리하고, **돌봄 알바**는 밥그릇을 채우고 아이들을 쓰다듬어 줍니다. 일당은 하루 끝에 빠져나갑니다.
6. **다친 아이 치료** — 길에서 붕대를 감은 아이를 만나면 간식 대신 **구급상자**(간식 가게 2,000원)로 치료해 줍니다. 고마워서 친밀도가 크게 오르고 간식 한 번이면 따라옵니다. 수집북에 치료 기록이 남습니다.

## 규칙

- **하루**: 09:00~21:00 (실제 약 150초). 끝나면 정산 화면이 뜨고 자동 저장됩니다. 카페를 열기 전에는 손님 없이 하루가 지나갑니다.
- **길에서 만나기**: 덤불·나무·연못가 풀밭에 아이들이 숨어 있습니다. 가까이서 빨리 움직이면 **경계심**이 올라 도망가고, Shift 로 천천히 다가가면 내려갑니다. 간식을 주면 **친밀도**가 오르고, 다 차면 주인을 따라옵니다. 카페 문으로 들어가면 식구가 됩니다.
- **간식**: 멸치 · 참치캔 · 츄르 · 육포. 고양이와 강아지가 좋아하는 정도가 다르고, 품종마다 **좋아하는 간식**(친밀도 1.8배)이 있습니다. 동네 간식 가게에서 삽니다.
- **품종**: 고양이 19종(치즈냥·턱시도·고등어·삼색이·흰둥이·까망이·러시안블루·샴·코리안숏헤어·페르시안·먼치킨·스코티시폴드·메인쿤·벵갈·랙돌·브리티시숏헤어·스핑크스·노르웨이숲·아비시니안), 강아지 19종(시바견·웰시코기·말티즈·푸들·닥스훈트·진돗개·골든리트리버·달마시안·비글·치와와·포메라니안·시베리안허스키·보더콜리·불독·사모예드·래브라도·요크셔테리어·비숑프리제·보스턴테리어). 장모종(페르시안·메인쿤·랙돌·노르웨이숲·포메라니안·허스키·사모예드·요크셔테리어·비숑프리제)은 털이 더 풍성하게 그려집니다. 도감은 16종씩 ←→ 로 넘깁니다. 흔함·가끔·희귀 세 등급이 있고 날이 갈수록 희귀한 아이가 조금 더 자주 나옵니다. 성격(소심·호기심·장난꾸러기·느긋함)에 따라 처음 경계심과 도망칠 확률이 다릅니다.
- **카페**: 손님은 아메리카노·카페라떼·핫초코·고양이 쿠키·치즈케이크 중 하나를 주문하고(2,500~5,500원), 주문을 받으면 자리에 앉아 아이들을 구경합니다. 좋아하는 종류(고양이파·강아지파·둘 다)의 아이가 기분 좋게 있으면 나갈 때 한 마리마다 팁 500원을 둡니다. 아이들의 **매력** 합계가 높을수록 손님이 자주 옵니다. 주문을 26초 안에 못 받으면 손님은 화내며 돌아갑니다(정산에 "놓친 손님"으로 기록).
- **알바**: 바리스타 일당 9,000원(주문 자동 처리), 돌봄 알바 일당 7,000원(밥그릇·쓰다듬기). 카페는 주인이 동네에 나가 있는 동안에도 계속 돌아갑니다.
- **돌보기**: 아이들은 시간이 지나면 배가 고파지고, 굶으면 기분이 나빠져 매력이 떨어집니다. 사료를 사서 밥그릇을 채워 두면 알아서 먹습니다. 쓰다듬어 주거나 손님이 쓰다듬으면 기분이 좋아집니다.
- **업그레이드** (카운터 옆 운영 메뉴): 귀여운 간판(손님 빈도), 푹신한 방석(기분 상한선), 큰 캣타워(매력), 가게 확장(수용 마리수 6 → 10).

## 테스트

Unity **Window > General > Test Runner** 의 EditMode 탭에서 실행합니다. 배치도 연결성, 도감·간식 카탈로그, 친해지기 로직, 경제·저장을 검사합니다. 편집기를 닫은 상태라면 터미널에서도 돌릴 수 있습니다.

```bash
/Applications/Unity/Hub/Editor/6000.0.84f1/Unity.app/Contents/MacOS/Unity -batchmode -projectPath . -runTests -testPlatform EditMode -testResults Logs/results.xml -logFile Logs/test.log
```
